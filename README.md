Para nuestro proyecto conocido como GU-IA, nosotros Gix Corp hemos desarrollado toda nuestra parte de programación en Visual Studio Code (Python) y n8n para asegurar el funcionamiento de nuestro proyecto y el orden, usando IA. Primero este sigue tres pasos fundamentales, la pregunta, el análisis y la respuesta; la primera parte involucra que el usuario ya registrado enciende el robot con el uso de un botón, al presionarlo entra en un corto periodo (5 segundos) en el cual se graba todo lo que dice (la pregunta) usando Py. Audio, estas preguntas pueden variar desde: “De que época es esta obra” a “Que significa esta obra”. Al hacer la pregunta, esta se guarda como un audio Wave el sistema y a través de n8n este lo mando a la Raspberry, esta pregunta se transcribe en texto para la IA poder entenderla y analizarla. En el n8n este primero comprende si esta es una obra verdadera que existe o no, esta función permite a el robot no confundirse con lo que esta viendo, luego crea una respuesta la IA trabajando bajo una descripción sobre que debe saber y explicar de la obra, como su origen, autor, técnicas, etc. Y finalmente al ya tener una respuesta concreta, esta usando Piper ahora transforma su respuesta en un audio, dándole mas vida a nuestro robot. Esta programación es lo que permite que nuestro robot tenga vida y funcione, mostrándole al mundo el proyecto de GU-IA.
